## 1. 先说结论：辨别黑中介，不靠感觉，靠三张证

不管对方自称"工厂 HR 直招""官方招聘""人才服务公司"还是"科技平台"，下面这三张证拿不出来，就别再聊了。

| 证件 | 颁发单位 | 不能没有的理由 | 公开查询入口 |
| --- | --- | --- | --- |
| **营业执照** | 市场监督管理局 | 经营范围必须含「人力资源服务」或「职业中介」 | 国家企业信用信息公示系统 `gsxt.gov.cn` |
| **人力资源服务许可证** | 当地人社部门 | 这是依法从事招聘代理业务的**法定行政许可** | 各地人社局官网 |
| **ICP 备案** | 工信部 | 任何在 ICP 备案的运营网站必备，且备案主体必须和域名所属公司一致 | 工信部 `beian.miit.gov.cn` |

加分项：能在国家知识产权局商标局查到的**注册商标**，至少能证明这不是临时凑的草台班子。

## 2. 蓝领招聘市场为什么这么乱

讲点行业实话。

正常的链路应该是：

```
工厂 HR ─→ 求职者
```

但市场上更常见的链路是：

```
工厂 HR ─→ 一级劳务代理 ─→ 二级中介 ─→ 街边黄牛 ─→ 求职者
```

每一层都要抽水。工厂明明开 28 元/小时，到工友手里可能只剩 22、甚至 18，这部分差价工友自己是看不见的。

更恶劣的是"先收费"模式：上来收 300—800 块的"介绍费/体检费/服装费"，再把你拉到一个跟说好的完全不一样的小厂，工资缩水、待遇缩水，想走？中介费不退。

知道这个，就知道为什么"避坑"比"找到工作"还重要。

## 3. 不被坑的实操方法（按重要程度排序）

### 3.1 上来要钱的，100% 是骗子

合规的招聘业务，**对求职者一定是免费的**。任何形式的"介绍费""办卡费""体检费""保证金""服装费"，听到就拉黑。合规平台的收入是从用工企业端拿服务费的，跟求职者无关。

### 3.2 拒绝脱离平台沟通

"加我微信详谈"是黑中介最常用的话术。一旦脱离平台：

- 没有聊天记录留底
- 平台无法追责
- 出了事维权无门

正规平台支持站内全流程沟通——看岗位、报名、面试预约、电子合同——没有"必须加微信"的环节。

### 3.3 工资必须"拆开看"

只给一个"综合月薪 7000—9000"的，必有猫腻。一份诚实的岗位描述至少要写清楚：

- 基本工资（写进合同的那一栏）
- 时薪 / 计件单价
- 加班费倍率（1.5×？2×？3×？）
- 加班时长怎么算
- 食宿是免费还是从工资里扣
- 五险有没有、什么时候交

合规平台的岗位详情会把这些一条条列出来；中介那边永远是"先来再说，到了厂里告诉你"。

### 3.4 警惕"工厂直招"四个字

最讽刺的是：**80% 以上的"工厂直招"反而是中介挂的**。怎么判断到底是不是真的直签？

1. **看运营主体**：在岗位详情或网页底部找运营公司名字，去 [国家企业信用信息公示系统](https://www.gsxt.gov.cn) 查它的经营范围，必须含"人力资源服务"四个字。
2. **看是否能出示与工厂的直签协议**：真直签的平台不会回避这个问题。
