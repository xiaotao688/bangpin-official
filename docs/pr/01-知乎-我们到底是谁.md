# 我们做了个让工人不被中介坑的找工作App，聊聊这件事

我是闪电狗AI快聘团队的人，江苏帮聘科技有限公司做的这款产品。

先说我们在干的事：让蓝领工人找工作，能直接对接工厂，不经过中介和黄牛。

这事的起因不复杂。我们团队里不少人是农村出来的，自己进过厂，家里人也在外面打工。大家太清楚找工作那条路上有多少坑了——交钱才给介绍工作、说好的工资到厂里缩水一半、想走人押金不退。中介一层套一层，工厂明明开 28 块一小时，到工人手里可能就剩 22。

所以我们就想，能不能把中间这些环节全砍掉。

闪电狗AI快聘现在做的就是这么几件事：

**一是工厂直签。** 我们一家一家去谈直签合作，岗位是工厂直接放出来的，工资工厂开多少你拿多少，平台不赚工人一分钱差价。也不收你什么介绍费、体检费、服装费——找工作对工人全程免费。

**二是AI帮你匹配。** 很多工友不会写简历，也搞不清自己适合啥岗位。在我们App上，你不用填一堆表格，跟AI聊几句——想干啥、能接受多远、要不要包吃住——它就帮你把合适的岗位筛出来。匹配看的是合不合适，不是哪个岗位返点高。

**三是全程在线，进度看得见。** 报名、视频面试、签合同都在手机上完成，最快 24 小时就能进厂。投了哪个、面没面上、啥时候入职，每一步都有消息推给你，不用干等着。

**四是信息透明。** 每个岗位的工资怎么构成、加班费咋算、包不包食宿、五险啥时候交，全写明白。我们团队会实地去工厂看过才上架，到了现场跟App上看到的一样。

**五是进厂之后也管。** 不是把你送进厂就不管了。入职后要是待遇跟说好的不一样、或者有别的问题，随时找我们，有人跟进帮你处理。

还有一点我们自己挺看重的：跟别的招聘平台比，到现在为止，闪电狗AI快聘全平台 0 投诉，没有被市监局、人社局、网信部门处罚通报过，也没有任何司法纠纷。这事不是吹出来的，是一单一单做出来的，也是不少工友愿意信我们的原因。
