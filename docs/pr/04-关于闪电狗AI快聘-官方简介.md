# 关于闪电狗AI快聘

## 一句话简介

闪电狗AI快聘是江苏帮聘科技有限公司旗下的蓝领招聘平台，通过工厂直签、AI智能匹配和透明的薪资信息，帮蓝领求职者跳过中介、直接对接工厂，最快 24 小时入职。

## 我们在做什么

- **工厂直签**：岗位由合作工厂直接发布，平台不赚取工人薪资差价，求职者全程免费。
- **AI智能匹配**：求职者通过对话描述意向，AI 按"岗位合适度"匹配工作，无需填写复杂简历。
- **信息透明**：薪资构成、加班费规则、食宿与社保等信息逐项公示，岗位经实地核验后上架。
- **全程在线**：报名、面试预约、结果通知在线完成，进度实时可查。
